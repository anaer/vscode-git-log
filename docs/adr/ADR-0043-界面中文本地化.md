# ADR-0043: 界面中文本地化

**状态：** 已接受
**创建时间：** 2026-11-09

> **当前状态 / 核心结论：** 两批迁移均已完成：`package.nls` 覆盖命令/菜单/配置，webview 用集中字典并注入 `vscode.env.language`，Git 错误消息与「下一步提示」走 `vscode.l10n` + `l10n/` bundle，缺 key 一律回退英文；`Dialogs.tsx` / `ContextMenu.tsx` 的对话框与右键菜单文案已全部迁入字典。无需后续动作。

---

## 背景

扩展界面全部为英文，README 虽提供中文版；中文用户在错误提示与对话框中的理解成本更高。引入自研 i18n 会增加一处真源，应优先使用宿主提供的本地化通道。

## 决策

1. **机制**：使用 `package.nls.json` / `package.nls.zh-cn.json` 与 `l10n/bundle.l10n.zh-cn.json`，不引入第三方 i18n 库；`package.json` 的命令标题、菜单与配置描述改为 `%key%` 引用，并声明 `"l10n": "./l10n"`。
2. **Webview 文案**：`createWebviewHtml` 把 `vscode.env.language` 写入 `<html lang>` 与 `<meta name="vscode-locale">`，前端字典 `t()` 据此选择中文或英文；缺 key 回退英文、完全未知的 key 返回 key 本身，不抛错。
3. **范围（已确认）**：命令标题、菜单、配置描述与枚举说明、通知、错误文案前缀与 Git 错误「下一步提示」、webview 静态文案均纳入翻译；Git 原始输出保持原文，本地化只包裹前缀与提示文本。`Git Log` 作为扩展品牌名（`category`、面板容器标题、视图名、顶层 `displayName`）保持英文，不列入翻译范围。
4. **术语一致**：与 `docs/glossary/glossary.md` 的中文译名对齐，同一概念只用一个译名。
5. **不做什么**：不翻译 Git 命令输出、不翻译代码注释、不新增第三种语言。

## 后果

- **收益：** 中文环境下命令面板、Git 错误提示与工作台文案可读性提升；复用宿主机制，无新增运行时依赖。
- **代价 / 权衡：** 新增文案必须同步英文与中文两份字典，漏改只在中文环境暴露；`classifyGitError` 因此依赖 `vscode` 模块，单测由 `test/support/vscodeMock.ts` 提供 `l10n.t` 桩；webview 包体随字典增加，体积预算由 400 KB 经 420 KB 调至 430 KB。
- **降级方向：** 宽松——缺翻译回退英文并照常工作，不阻断任何功能。
- **未解决风险：** webview 侧语言在窗口运行期切换时不会自动重渲染，需下次打开生效。

- 扩展侧文案与配置：`package.json`，上述字段统一改为 `%key%` 引用。
- webview 文档注入：`src/webview/createWebviewHtml.ts#createWebviewHtml`；调用方 `src/webview/WorkbenchPanel.ts`。

- 已迁移的 webview 静态文案：`webview/src/RefsPane.tsx`、`webview/src/FilesPane.tsx`、`webview/src/DetailsPane.tsx`、`webview/src/Toolbars.tsx`、`webview/src/App.tsx`、`webview/src/CommitList.tsx`、`webview/src/DateRangePicker.tsx`、`webview/src/Dialogs.tsx`、`webview/src/ContextMenu.tsx`；字典按区域组织（第二批新增 `webview.stash` / `webview.amend` / `webview.historyParent` / `webview.squash` / `webview.editMessages` / `webview.rewriteAuthor` / `webview.namedOperation` / `webview.cleanup` / `webview.folderDelete` / `webview.menu` / `webview.common`）。

- 术语对照：`docs/glossary/glossary.md`。

## 验证

- `test/unit/packageNls.test.ts`：两套 nls 的 key 集合一致且无空值；`package.json` 中全部 `%key%` 均可解析、无孤儿 key；所有已贡献标签、描述与枚举说明均走 key 引用。
- `test/unit/webviewI18n.test.ts`：中文环境取中文、非中文取英文、中文缺 key 回退英文、未知 key 返回 key、占位符在两种语言下均可插值，且两套字典 key 集合一致、占位符一一对应；该用例同时覆盖第二批新增的对话框与右键菜单 key。
- `test/unit/webviewHtml.test.ts`：缺省输出 `lang="en"`，传入 `zh-cn` 时 `<html lang>` 与 `vscode-locale` meta 同步。
- `test/unit/l10nBundle.test.ts`：bundle 无孤儿 key（每个 key 仍出现在 `classifyGitError.ts`）且无空译文；`package.json` 声明 `./l10n`。
- `test/unit/GitErrorClassifier.test.ts`：英文原文作为 l10n key 保持不变，既有分类与「下一步提示」断言不回归。
